# Retail Sales Analysis

## 1. Project Overview
This project is an end-to-end analysis of two years of retail sales for a chain of 8 stores across 4 regions. 
It covers the full analytics workflow: defining business questions, cleaning messy data in Excel, designing and loading a MySQL database, analyzing the data with SQL, and presenting the results in an interactive Excel dashboard.

**Purpose**: To build a portfolio project that demonstrates practical data analytics skills, from raw data to business recommendations.

Business questions
1. Who are our top customers and products?
2. How much revenue and profit were made by month, quarter, and year?
3. How do stores and regions perform, and is there seasonality?
4. How long does shipping take, and does it vary by store, region, or month?
5. What impact do discounts have on profit?
**Note on question design:** an earlier version asked whether shipping time affects the order rate.
That cannot be answered, because the data only contains orders that happened (no abandoned carts or lost orders), so the question was reframed around how shipping time varies.

## 3. Tools and Technologies

The following tools were used:

- **Microsoft Excel:** Data cleaning, data analysis, PivotTables, charts, and dashboard development.
- **MySQL:** Data exploration, data cleaning, and querying.
- **GitHub:** Project organisation, documentation, and version control.

## 4. Project Structure

The project is organised into four main folders:

- **Excel:** Contains the Excel workbook, including the raw dataset, cleaned dataset, PivotTables, and dashboard.
- **SQL:** Contains the SQL scripts used for data cleaning and analysis.
- **Documentation:** Contains written explanations of the project, methodology, and findings.
- **Images:** Contains screenshots and visual representations of the analysis and dashboard.

## 5. Project Deliverables

The final deliverables include:
• A cleaned dataset
• A MySQL database with four related tables
• A set of documented SQL scripts
• An Excel dashboard with KPI cards, charts, and slicers
• This documentation and a GitHub README

## 6. Project Outcome

This project demonstrates the application of Excel and SQL in transforming raw sales data into meaningful business insights. It also highlights the importance of data cleaning, analytical thinking, and data visualisation in supporting business decisions.
