# Data Dictionary

## 1. Dataset Overview

The sales_raw table contains approximately 9,802 cleaned order-line records from a retail sales dataset.

An order may contain one or two lines; therefore, `order_id` is not unique and can appear more than once.

The table was cleaned and structured in MySQL for further analysis.

## 2. Table: sales_raw

| Column Name | Description | Notes |
|---|---|---|
| order_id | Identifies the customer order. | May repeat for multi-line orders. |
| order_date | Date the order was placed. | Mixed date formats converted; day/month swaps corrected in approximately 3% of rows. |
| order_year | Year in which the order was placed. | Derived from order_date. |
| order_month | Month in which the order was placed (1–12). | Derived from order_date. |
| ship_date | Date the order was shipped. | |
| shipping_days | Number of days between order placement and shipment. | Derived; valid range is 1–7 days. |
| customer_id | Identifies the customer associated with the order. | Links to the customers table. |
| product_id | Identifies the product sold. | Links to the products table. |
| store_id | Identifies the store associated with the sale. | Links to the stores table. |
| quantity | Number of units sold on the order line. | Valid range is 1–8; negative and extreme values were corrected. |
| discount | Discount applied to the order line. | Stored as a fraction (0.10 = 10%). NULL represents unknown, not zero. |
| payment_method | Payment method used by the customer. | Credit Card, Debit Card, Cash, Mobile Money, Bank Transfer, or Unknown. |
| sales | Revenue generated by the order after discount. | |
| profit | Profit generated from the order. | Calculated as sales minus (unit_cost × quantity). Can be low or negative at deep discounts. |

## 3. Important Data Notes

- The dataset contains approximately 9,802 records after cleaning.
- Each record represents an individual order line, not necessarily an entire order.
- `order_id` is not unique because some orders contain multiple products.
- `line_id` was introduced as the primary key to uniquely identify each order line.
- Derived fields include `order_year`, `order_month`, and `shipping_days`.
